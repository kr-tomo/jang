# 장기 (Janggi) — 웹 앱 / PWA

2인 대국, 컴퓨터(쉬움·어려움) 대국, 변형 룰 옵션, 첫 수 전 상차림 선택을 지원하는 장기 게임입니다.
빌드 과정이 없는 순수 HTML/CSS/JS 입니다.

## 실행

PWA(설치·오프라인)는 `http(s)`로 열어야 동작합니다. 아무 정적 서버면 됩니다.

```bash
cd janggi
python3 -m http.server 8000     # 또는: npx serve
# 브라우저에서 http://localhost:8000
```

GitHub Pages 등에 폴더 내용을 그대로 올리면 모바일에서 "홈 화면에 추가"로 설치됩니다.
파일을 고쳤다면 `sw.js`의 `VERSION` 값을 올려야 설치된 앱의 캐시가 갱신됩니다.

## 기능

- 모드: 2인 / 컴퓨터 쉬움 / 컴퓨터 어려움 (컴퓨터 대국은 초·한 선택, 한으로 두면 판이 회전)
- 첫 수 전 상차림 선택: 마상마상 · 마상상마 · 상마마상 · 상마상마 (각 진영 자기 기준)
- 규칙 옵션 (언제든 켜고 끔, **이후 두는 수부터 적용**)
  - 빅장: 켜면 두 장이 마주 보는 즉시 종료(무승부, 점수제와 함께면 점수 판정) / 끄면 마주 보는 수는 불가
  - 한수쉼: 장군이 아닐 때 차례 넘기기 (둘 수 있는 수가 없으면 자동 한수쉼)
  - 점수제: 빅장·연속 한수쉼 시 기물 점수로 판정 (차 13·포 7·마 5·상 3·사 3·졸 2, 한 덤 1.5)
  - 3회 반복 무승부 (켠 시점부터 집계)
- 무르기, 기권, 자동 저장/이어하기
- 어떤 화면 비율에서도 스크롤 없이, 판이 가장 크게 배치되고 UI는 중앙 기준으로 정렬

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css`, `app.js` | 화면, 입력, 컴퓨터 상대 연결 |
| `layout.js` | 화면 비율별 배치 계산 (세로/가로 배치 중 판이 더 큰 쪽 선택) |
| `engine.js` | 장기 규칙 (수 생성, 장군 판정, 빅장) |
| `ai.js`, `worker.js` | 컴퓨터 상대 (알파-베타 탐색, 웹 워커로 실행) |
| `game.js` | 규칙 옵션 적용, 종료 판정, 무르기, 저장 |
| `theme.js`, `assets/` | **스프라이트 설정과 이미지** |
| `manifest.webmanifest`, `sw.js`, `icons/` | PWA |
| `tools/` | 에셋 생성 스크립트와 테스트 (`node tools/test-*.js`) |

## 장기말·장기판 교체 (스프라이트)

`theme.js` 하나에 모든 좌표가 있습니다.

- `assets/pieces.svg` : 말 시트. 192×192 프레임, 가로 7칸(장·차·포·마·상·사·졸/병) × 세로 2줄(위 초, 아래 한)
- `assets/markers.svg` : 표시 시트. 128×128 프레임 6개 (선택, 직전 수 출발/도착, 이동 가능, 잡기, 장군)
- `assets/board.svg` : 판 이미지. 920×1020, 첫 교차점 (60, 60), 한 칸 100

같은 레이아웃의 PNG/WebP/SVG로 파일만 바꾸면 되고, 레이아웃이 다르면 `theme.js`의 `image`, `sheetW/H`, `frames` 좌표를 고치세요.
말을 더 크게/작게 보이려면 `pieces.scale` 을 조절합니다.
기본 에셋은 `python3 tools/make_assets.py` 로 다시 만들 수 있습니다(fontTools·Pillow 필요).
